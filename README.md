# 通风与空调 · 期末刷题站

根据《通风与空调工程》（第三版）分单元练习题库整理的静态刷题网站。

包含 **156 道原文客观题**：单选 65 题、多选 37 题、判断 54 题。保留原文选项、答案、解析及单元归属；不包含简答题、计算题。原文没有单元 11。

## 功能

- 顺序练习、随机练习、按单元或题型筛选与关键词搜索。
- 单选和判断即时判分，多选需确认提交，完整匹配才算正确。
- 错题自动收集，答对后自动移出；支持收藏重点题。
- 模拟考试可选题量和时长，按题型比例随机抽题、到时自动交卷、逐题回顾。
- 学习进度、收藏、错题和最近 20 次考试保存在当前浏览器的 localStorage。
- 适配手机、平板和电脑；支持键盘选项 A–E、方向键切题。

## 本地使用

将所有文件保存在同一目录，打开 `index.html` 即可使用。也可通过任意静态 HTTP 服务器运行。

无需安装依赖、构建工具或服务器后端。网页使用相对资源路径，适用于 GitHub Pages 的项目子路径。

## GitHub Pages

仓库 Settings → Pages，选择 **Deploy from a branch**，分支 `main`、目录 `/ (root)`，保存后等待发布完成。

## 计分与数据

模拟考试各题等权，总分 100 分，80 分及格；多选漏选、错选、多选和未作答均不得分。该规则用于本站自测，不代表学校的正式考试安排。参考答案与解析依据原文题库。

数据仅保存在当前浏览器，清理网站数据、切换设备或浏览器后不会自动同步。考试刷新后恢复原截止时间；关闭页面后再打开，超时的试卷会自动交卷。请勿把本地练习记录当作跨设备云备份。

## 文件

- `index.html`：页面入口。
- `styles.css`：响应式样式。
- `app.js`：练习、计分、进度保存与考试逻辑。
- `questions.js`：原文题目与答案数据。
- `favicon.svg`：网站图标。
- `.nojekyll`：直接由 GitHub Pages 提供静态文件。
